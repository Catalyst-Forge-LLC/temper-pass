A called pass. Only run it when you have asked for it.

**Status:** Locked. Same-session validation, including a run that failed by inventing nouns.

A scope lock is a short written contract. The value concentrates in the non-goals list: the part people skip, and the part that prevents drift.

**Use when** you ask to lock scope, freeze requirements, or write a contract for what is in and out. **Do not use** unprompted, or while the problem is still being found.

Skill file: [`passes/scope-lock/SKILL.md`](https://github.com/Catalyst-Forge-LLC/temper-pass/blob/main/passes/scope-lock/SKILL.md)

## Protocol

1. Restate the problem in one sentence, using only nouns already on the table. If you cannot, stop.
2. List what is explicitly *not* being solved. If a reader could assume it is in, and it is not, it belongs here.
3. Define done as an observable condition, not a feeling. Do not demand numbers the user did not state.
4. Name what would justify reopening scope: a trigger, not a vibe.
5. Hand back the artifact (Problem / In / Not in / Done / Reopen if) and stop.

If the input is too soft, do not produce a full-dress contract of nothing.

A first run on "scope-lock hiring a senior engineer" invented a contract. Step 1 now forbids new nouns. Transcripts: [`examples/scope-lock-transcripts.md`](https://github.com/Catalyst-Forge-LLC/temper-pass/blob/main/examples/scope-lock-transcripts.md).
